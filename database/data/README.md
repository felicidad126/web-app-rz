# Data referensi awal

File di folder ini dipakai `ReferenceDataSeeder`.

| File | Isi | Catatan |
|---|---|---|
| `icd10_dental_starter.csv` | Daftar awal kode ICD-10 (WHO) yang umum di klinik gigi | **Bukan daftar lengkap.** Impor daftar ICD-10 resmi (Kemenkes/SATUSEHAT) lewat menu *Master Klinis → ICD-10 → Import CSV*. |
| `icd9cm_dental_starter.csv` | Daftar awal kode tindakan ICD-9-CM (vol. 3) untuk kedokteran gigi | Sama: impor daftar lengkap lewat menu *ICD-9-CM → Import CSV*. |

Nama Bahasa Indonesia adalah terjemahan kerja dan sebaiknya direview oleh dokter gigi / perekam medis klinik.
